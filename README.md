# كيوبسات — موقع تعليمي تفاعلي بالعربية

صفحة واحدة (`index.html`) عن الكيوبسات (CubeSat)، فيها:

- مجسّم ثلاثي الأبعاد لكيوبسات 3U: تدوير وتقريب، تفكيك مع تسميات للأجزاء، طيّ ونشر الألواح والهوائيات، ومعلومات كل نظام فرعي.
- مقارنة الأحجام من 1U إلى 12U بمقياس رسم موحّد.
- رحلة القمر الصناعي في سبع مراحل، لكل مرحلة رسم متحرك (مع تشغيل تلقائي).
- أقمار عربية، واختبار قصير، ومسرد للمصطلحات، والمصادر.
- صورة معاينة للمشاركة (`og.png`) تظهر عند إرسال الرابط في تطبيقات المحادثة.

إعداد: Ameer Hamam — مشروع تعليمي، وليس صفحة رسمية للاتحاد العربي لعلوم الفضاء والفلك.

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة. يحتاج الاتصال بالإنترنت لتحميل three.js (r128) من cdnjs وخطوط Google Fonts؛ وفي غياب الخطوط تُستخدم خطوط النظام.

لتشغيله على خادم محلي:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
1. من إعدادات المستودع: **Settings → Pages**.
2. **Source:** Deploy from a branch.
3. **Branch:** `main`، والمجلد `/ (root)`، ثم **Save**.
4. يظهر الرابط بعد دقائق: `https://<username>.github.io/cubesat-arabic/`.

## ملاحظات تقنية
- ملف واحد بدون أدوات بناء: CSS وJS مضمّنان.
- المكتبة الخارجية الوحيدة: three.js `r128` من cdnjs (بإصدار محدد).
- الرسم ثلاثي الأبعاد يتوقف عند خروج المجسّم من الشاشة، وكثافة البكسل محدودة بـ 1.5 على الهواتف.
- يحترم `prefers-reduced-motion`، ويعمل بقية المحتوى دون WebGL.
- لوحة المفاتيح على المجسّم: الأسهم للتدوير، `+`/`−` للتقريب، `E` للتفكيك، `Esc` لإلغاء التحديد.
- رابط صورة المعاينة في وسوم `og:image` مضبوط على `https://itsak7m.github.io/cubesat-arabic/og.png`؛ عدّله إن تغيّر رابط النشر.
